# Support

Use GitHub Issues for reproducible collection, classification, publication, retained-state, or documentation defects and bounded feature proposals. Include the affected profile/revision, expected and observed behaviour, and the smallest useful evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md).

The monitor owns its observation, taxonomy and reporting logic. Monitored organizations retain authority over their repositories and do not inherit the monitor's classifications as official statements.
