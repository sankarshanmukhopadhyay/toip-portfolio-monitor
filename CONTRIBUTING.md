# Contributing

For substantive changes, preserve an Issue → PR → tests/evidence → merge trail. State the observed problem or proposition, affected ecosystem/profile and authority boundary; implement the smallest coherent change; add regression/negative evidence for consequential behaviour; and merge only after applicable validation passes.

Do not force ambiguous external repositories into a taxonomy merely to eliminate `Unclassified`. Missing or ambiguous evidence must remain explicit.

Security reports must follow [`SECURITY.md`](SECURITY.md).
